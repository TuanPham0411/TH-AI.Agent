Use your Windows Oracle DSN.

A local DSN is not an HTTPS URL. Use DSN on a paired computer unless you already operate a separate HTTPS gateway.

  1. In Connections → Pair / manage a computer, create a pairing token and run the displayed installer on the Windows machine that owns the DSN. Keep -EnableOdbc enabled. It installs pyodbc for the selected Python. Full computer control is optional for read-only ODBC.
  2. Python and your Oracle ODBC driver must both be 32-bit or both 64-bit. On 64-bit Windows, C:\Windows\System32\odbcad32.exe manages 64-bit DSNs; C:\Windows\SysWOW64\odbcad32.exe manages 32-bit DSNs. Use -PythonPath "C:\path\to\matching\python.exe" if the installer selects another runtime.
  3. Keep the existing DSN/TNS settings. Test Connection inside Oracle ODBC Administrator first. User DSNs must belong to the same Windows account as the agent.
  4. Return to Connections, choose ODBC / DSN and configure the fields below.
  5. Save, then choose Test saved connection. Keep the agent online and the laptop awake while querying.

The existing Oracle TNS Service Name, such as SGPODS, stays in your Windows DSN. No gateway URL/token is needed in paired-computer mode. This connector uses read-only operations and does not change your DSN.

IM002: DSN not visible/driver missing. IM014: 32/64-bit mismatch. 28000: database login. 08001: network/TNS service. The actual Oracle installation must be tested on your machine.
