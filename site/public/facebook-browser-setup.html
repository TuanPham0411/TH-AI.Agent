Facebook in your local browser

The device agent opens a dedicated visible Chrome or Edge profile. Your Facebook session stays on that computer. No Facebook access token or password is stored on the server.

1. Update the paired Windows agent

Download the installer, then run in PowerShell under the Windows account you use for Facebook:

Invoke-WebRequest -UseBasicParsing https://thienha.io.vn/install-th-device.ps1 -OutFile "$env:TEMP\install-th-device.ps1"
& "$env:TEMP\install-th-device.ps1" -EnableFacebookBrowser -BrowserChannel chrome

Chrome must be installed. Use -BrowserChannel msedge for Edge, or -BrowserChannel chromium to download Playwright Chromium. Existing pairing and other enabled tools are preserved. If this is your first installation, create a device in Connections → Pair / manage a computer and supply its one-time pairing token to the installer.

2. Add a connection

Choose Facebook · Browser on your computer, a computer reporting the Facebook browser actions, and the exact posting identity name shown by Facebook, and a fixed URL such as https://www.facebook.com/YourPage. Save the connection.

3. Sign in locally

Choose Open Facebook sign-in. Complete login and any OTP/CAPTCHA in the browser that opens on your computer. Close that automation window, then choose Test connection. Do not send a password, OTP or cookie in chat. This profile is separate from your usual browser windows.

4. Review and publish

Ask the assistant to use this connection. A publish block supports a caption, HTTPS link, up to four local image/video paths under approved roots, or one saved server asset (assetId, JPEG/PNG/WebP/MP4/MOV, up to 20 MB). A media → publish workflow automatically archives generated output for the browser upload. Other remote media URLs must first be saved as an asset; they are not silently omitted. Review the actual payload before approval.

The agent opens the destination, fills the composer, uploads media and clicks Post. It reports success only after finding a new matching post permalink, then closes its own window. If confirmation is missing after the click, the result is uncertain; check Facebook before retrying. Facebook UI changes or restrictions can require your intervention.

Availability

The computer must be awake, online and logged into an interactive desktop. Laptop browser connections cannot be enabled as independent server automation. Closing the website tab does not cancel already approved device work. The agent does not bypass login challenges or control unrelated browser windows.
